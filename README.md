# 📝 Todoey Flutter App

A beautiful and responsive Flutter todo app integrated with Firebase for real-time backend support, enhanced by smooth Hero animations and clean UI design principles.

---

## 🚀 Features

- 🔥 **Firebase Firestore Integration**
  - Real-time creation, updating, and deletion of todos.
  - Seamless data sync between app and cloud.
  - Includes Firebase Authentication.

- 🎬 **Animations**
  - Smooth, shared-element transitions between todo list and detail views using Flutter’s `Hero` widget.
  - Enhances user experience with visually appealing animations.

- ⚙️ **State Management using Provider**
  - Efficient and clean separation of logic and UI.
  - Simplifies dynamic UI updates when data changes.

- 📦 **Modular & Scalable Codebase**
  - Clear project structure for easy navigation and expansion.
  - Ideal for learning or further development.
